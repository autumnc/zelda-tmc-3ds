# Optional cheats.txt override for The Minish Cap 3DS
#
# The build already ships this exact list compiled in, so no file is required.
# Copy this file to the app folder (same folder as the ROM) and rename it
# cheats.txt ONLY to replace the built-in list with your own codes:
#
#   sdmc:/3ds/The Minish Cap 3DS/cheats.txt
#
# Press L + R + SELECT in-game to open the cheat menu. Names must be ASCII:
# on a JP-ROM build the CJK font is disabled, so the menu cannot render
# non-ASCII characters.
#
# Addresses are the stock VBA/GameShark GBA codes; the port re-bases them onto
# the game's relocated state automatically, so use the addresses as-is.
#
# Format:
#   name ADDR:VALUE   starts a cheat (8-hex address, value 2/4/8 hex digits
#                     = 1/2/4 bytes)
#   ADDR:VALUE        adds another write to the current cheat
#   # comment / blank lines are ignored
